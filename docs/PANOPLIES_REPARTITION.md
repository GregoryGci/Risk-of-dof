# Répartition des panoplies Dofus 1.29 — proposition avant intégration

Source : base SunDofus 1.29, noms et visuels recoupés avec le cache du client Retro local. Les familiers et les sacs sont rattachés aux emplacements existants ; les Dofus gardent leur table de boss indépendante. Les entrées sans deux pièces équipables vérifiables sont écartées et signalées. Les objets gardent leur niveau réel ; le palier sert à limiter leur zone de drop.

Chaque zone ne donne que son palier. Bouftou et Meulou restent dans leurs donjons ; pour les autres, la tranche de niveau passe avant le thème lorsque le donjon arrive trop tôt ou trop tard dans la campagne.
