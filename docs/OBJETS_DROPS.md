# Équipements, taux de drop et jets parfaits

Catalogue généré depuis les données du jeu : **82 objets**, dont **10 Dofus**.

- Chaque monstre ennemi : **3 %** de chance d'équipement permanent, partagé uniformément entre les équipements accessibles.
- Chaque boss : un second tirage indépendant de **3 %** de chance de Dofus, partagé uniformément entre les Dofus accessibles. Les autres monstres ne donnent jamais de Dofus.
- Après un drop : normal **80 %**, rare **16 %**, épique **3,5 %**, légendaire **0,5 %**. Soit, pour une catégorie de butin entière : normal **2,4 %**, rare **0,48 %**, épique **0,105 %**, légendaire **0,015 %** par ennemi éligible.
- Les taux du tableau sont les probabilités **d'un objet précis par monstre** (par boss pour les Dofus), à la première zone où son palier est accessible. Ils diminuent quand davantage d'objets deviennent éligibles. Les difficultés conservent ces taux ; les modes difficiles produisent davantage de monstres.
- Chaque fin de run donne aussi **un équipement garanti du palier atteint**, jamais un Dofus, avec la même distribution des raretés. Ce bonus de fin de run n'est pas inclus dans les taux par monstre.
- Tous les exemplaires d'un même objet / rareté / tier ont exactement les mêmes stats : normal **55 %**, rare **75 %**, épique **90 %**, légendaire **100 %** du jet parfait, avec l'arrondi du jeu.
- Fusion : **10 identiques** donnent **1** objet de rareté supérieure. Dix légendaires tier 1 donnent un légendaire tier 2 ; dix tier 2 donnent un tier 3. Chaque tier de forge ajoute **25 % du jet parfait de base**. Les piles sont distinctes par objet, rareté et tier.
- Six emplacements de Dofus ; **un seul Dofus du même nom**, toutes raretés et tiers confondus. Les doubles anneaux nécessitent deux exemplaires.
- Les niveaux 20/40/80/120/160 sont des paliers propres à Risk of Dof, pas les niveaux d'équipement officiels Retro. Aucun PA : les bonus correspondants sont adaptés à la vitesse de recharge.

Les jets de toutes les raretés sont également disponibles dans [objets-drops.csv](objets-drops.csv).
